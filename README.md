# erfan-khalaji.github.io

Personal site. One hand-written HTML file, no framework, no build step.

- `index.html` holds all content and styles. Edit it directly.
- `assets/photo.jpg` is the only binary file.
- Pushing to `main` deploys to GitHub Pages via `.github/workflows/deploy.yml`.

Preview locally with `python3 -m http.server 8000` and open http://localhost:8000.
